# Faculdade

Repositório com os materiais e códigos que desenvolvi ao longo do curso de
**Ciência da Computação** na **Universidade Federal de Jataí (UFJ)**.

## Organização

| Pasta | Disciplina | Conteúdo |
|-------|------------|----------|
| [`ED1`](./ED1) | Estrutura de Dados I | Listas, filas, pilhas, paradigmas e revisões de prova |
| [`ED2`](./ED2) | Estrutura de Dados II | Árvores (árvore B) e exercícios |
| [`Programa Orientado a Objeto`](./Programa%20Orientado%20a%20Objeto) | Programação Orientada a Objetos | Sistema acadêmico em Java (com interface gráfica) |
| [`Banco de dados I`](./Banco%20de%20dados%20I) | Banco de Dados I | Modelagem no MySQL Workbench |

## Observações

- Os arquivos compilados (`.exe`, `.class`) não são versionados — veja o [`.gitignore`](./.gitignore).
- Em `ED1/Rev prova` ficam as questões e revisões usadas para estudo de prova.
